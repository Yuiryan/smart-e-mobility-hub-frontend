# Phạm vi frontend hiện tại

Toàn bộ UC00–UC15 do bạn phụ trách. Phân công hai thành viên trước đây không còn áp dụng.

| Nhóm      | Các màn hình                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------- |
| UC00      | Chọn vai trò, đăng nhập, đăng ký, khôi phục mật khẩu, xác nhận mã, đặt lại mật khẩu, thành công/lỗi |
| UC01–UC07 | Trang chủ, tìm Hub, chi tiết xe, giữ xe, đặt chỗ đỗ, quét QR, trả xe, đăng ký sạc                   |
| UC08–UC12 | Tổng quan, can thiệp, cảnh báo, điều phối, sự cố                                                    |
| UC13–UC14 | Đề xuất lịch sạc, chỉnh/xác nhận lịch; kịch bản mô phỏng, kết quả, đề xuất điều phối                |
| UC15      | Việt/Anh, sáng/tối, lưu lựa chọn giao diện                                                          |

Ưu tiên hiện tại là UI theo Figma và các ảnh/component đã cung cấp. Các thao tác demo hỗ trợ kiểm tra trạng thái giao diện; tải lại trang đặt lại dữ liệu. Không bổ sung tích hợp API trong đợt chỉnh UI này.
